Installation

Install Detour
in a few simple steps.

Follow the instructions below for your device. It only takes
a minute to get started.

Scan to open Detour

Use your phone's camera to scan the QR code
and install the app instantly.

This page is running on your computer, so the code only works on the same Wi-Fi. Open it from the live site to share it.

Install on Android

  1. 1Open this page in Chrome.
  2. 2Tap Install, or open the browser menu and select Install app.
  3. 3Open Detour from your home screen and choose your role.

Install on iPhone

  1. 1Open this page in Safari.
  2. 2Tap Share, then Add to Home Screen.
  3. 3Open Detour and choose your role.
